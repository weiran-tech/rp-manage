# Mock 数据与边界

Mock 对开发与生产构建均生效，不发送后端请求。数据保存在 `localStorage.prototype_mock_v1`。种子包含 28 个用户、2 个角色、菜单、字典、配置、地区及日志。

支持列表查询、分页、常用筛选、详情、创建、更新与删除；配置分组、字典项、收藏、偏好、资料与密码也保存在本地。

## 演示能力

| 能力 | 行为 |
| --- | --- |
| 登录 | admin / admin123；短信码 123456，不发送短信 |
| 权限 | 默认全部权限，仅模拟界面 |
| SSO | 无提供方，不连接外部服务 |
| 上传 | 保存 data URL，本地预览；每个文件最多 3 MB，总量受 localStorage 限制 |
| 批处理 | 接收文件后生成 3 条固定模拟成功结果，不解析文件 |
| 自增序号 | 同一标识在本地递增 |
| 地区导出 | 浏览器生成 UTF-8 CSV |
| 日志 | 固定种子用于展示，不作为审计记录 |

修改页面或数据契约时同步调整 seed.ts 与 transport.ts。未知操作返回明确错误，避免界面误报成功。

清除 `prototype_mock_v1` 后刷新即可恢复初始数据。已有存储不会自动合并新种子，生成新原型或更换菜单后需重置。
